English learning system · mastery-gated, open source

學會，而不是趕上

大多數英語計畫的骨架是日曆：第幾週做什麼。這套系統的骨架是通過條件：達到什麼才能往下走。差別不只是形式——趕進度時，人會挑「看起來有進度」的活動；沒有截止日時，才敢做那些真正推動能力、卻慢得塞不進短期計畫的事。

三份文件

01

五關框架

主線。累積輸入 → 注意力精修 → 受控輸出 → 自由輸出 → 用它做事，每一關附一個可以自己測的通過條件、常見卡點，以及「為什麼多數人在第三個月停掉」的對策。

先讀這份

02

經歷語料庫

把你真實的經歷寫成可重複使用的英文段落：五塊結構、填空模板、一個虛構範例與共用語塊。是第三、四關最好的練習材料，因為練的是你真的要講的內容。

通過第二關之後開始建立

03

考試軌道

需要正式成績時的一條窄軌。TOEFL 2026 改制重點、IELTS 電腦化、CEFR 分數對照、所需時間的算法，以及八週衝刺模板。

通過第三關之後才進去

三個 AI 教練 skill

倉庫的 skills/ 下有三個 skill，讓 AI 助理扮演固定角色，而不是每次重下指令。它們共用一條規則：不給你背模板——高階評分標準本身就在扣模板化的回答。

writing-coach對照官方評分標準逐條批改，引用你原文的句子指出扣分點，示範「差一級」長什麼樣。不重寫整篇，每次只要求你修一到兩個問題。
speaking-drill出題陪練，或收你的錄音逐字稿做分析。用數字講話：填充詞次數、重複句型、時態錯誤位置，每次抽五個可背的語塊。
story-bank維護語料庫。照五塊結構把新經歷寫成英文段落，並被明令不得編造數字——不知道就留空並直接問你。

安裝方式依你使用的助理而定：多數支援 skill 的工具只要把資料夾放進它的 skills 目錄即可。詳見倉庫 README.md。

從哪裡開始

讀完五關框架，誠實地自測你在第幾關——多數自認中階的人其實還沒通過第一關。然後設定你的每日地板，低到最糟的一天也做得到。

第一週不要改變任何事，只記錄你實際做了什麼。你需要的是真實基線，不是計畫。

這套系統刻意不綁定特定考試、語言程度或學習者背景。所有難度標準與時數估計都是規劃用的經驗法則，不是精確的測量值。
